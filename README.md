# WinShutDown — выключение компьютера по расписанию

Программа для родительского контроля под Windows 10 и 11. В заданное время она **принудительно выключает компьютер**.
Расписание задаётся отдельно на каждый день недели, например в будни до 22:00, а в пятницу и субботу до 23:30.
Перед выключением на всех мониторах появляется крупная надпись поверх окон, **«Осталось 30 минут»**, а голос говорит
**«Осталось 30 минут до выключения компьютера»**. Когда предупреждать, задаётся в настройках, например `30, 10, 5`:

- **промежуточные предупреждения** (за 30 и за 10 минут) — надпись на 20 секунд и голосовое предупреждение;
- **последнее предупреждение** (за 5 минут) — надпись остаётся на экране до самого выключения, голос повторяет
  предупреждение каждую минуту, а в последние 10 секунд считает «10, 9, 8…».

Сквозь надпись можно кликать, чтобы успеть сохранить работу.

**Голос.** Программа использует встроенный в Windows синтез речи, а фразу составляет сама: число и окончание
(«минута», «минуты», «минут») подставляются автоматически. Нужен русский голос: в русской Windows он уже есть,
в английской добавляется через «Параметры → Время и язык → Речь → Добавить голоса → Русский». Проверить голос можно
кнопкой «Прослушать» в настройках. Если русского голоса нет или голос выключен в настройках, вместо него звучит
звуковой сигнал.

### Видно ли предупреждение поверх игры?

Программа никогда не сворачивает игру и не забирает у неё управление.

- **Игра в окне или в «оконном полноэкранном» (безрамочном) режиме** — надпись видна поверх игры, голос слышно.
- **Игра в «эксклюзивном полноэкранном» режиме** (например, Overwatch в режиме «Полный экран») — поверх такой игры
  Windows не показывает окна других программ, поэтому надпись не видна, но **голос слышно**, в том числе в наушниках.
- **Выключение** происходит в любом случае.

Программа — один файл `WinShutDown.exe`, ничего доустанавливать не нужно (.NET Framework 4.7.2+ уже есть
в Windows 10 и 11). Готовый файл можно скачать в разделе [Releases](../../releases) или собрать из исходников
(см. «Для разработчика»).

## Установка (на компьютере ребёнка)

1. Скопируйте `WinShutDown.exe` на компьютер, например в «Загрузки».
2. Запустите его. Windows запросит права администратора — введите пароль администратора.
   *Если появится синее окно SmartScreen «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»:
   у программы нет платной цифровой подписи.*
   *Если в Windows отключён контроль учётных записей (UAC), запросить права из обычной учётной записи нельзя.
   Тогда войдите в Windows под учётной записью администратора и запустите программу там — она об этом подскажет.*
3. В окне установки задайте:
   - **Расписание на каждый день недели** — «Можно с» и «Выключать в». Например, понедельник 07:00–22:00,
     суббота 09:00–00:30. Если «Выключать в» меньше, чем «Можно с», выключение произойдёт после полуночи
     (в примере — в ночь на воскресенье в 00:30). Если снять галочку «Ограничить», день будет без ограничений.
     Вне указанного времени компьютером пользоваться нельзя: если ребёнок его включит, после предупреждения он
     снова выключится;
   - **Предупреждения** — за сколько минут до выключения показывать надпись «Осталось X минут». Можно указать
     несколько значений через запятую, например `30, 10, 5`;
   - **Пароль родителя** — без него нельзя изменить настройки или удалить программу.
4. Нажмите **«Установить»**. Скачанный файл после этого можно удалить: программа скопирована в `C:\Program Files\WinShutDown`.

### Обязательно

- **Учётная запись ребёнка должна быть «Стандартной», а не «Администратором».** Проверить можно в разделе
  «Параметры → Учётные записи → Другие пользователи» (в Windows 10 — «Семья и другие пользователи»).
  Если у ребёнка права администратора, обойти любую подобную программу несложно.
- У учётной записи администратора должен быть пароль, и ребёнок не должен его знать.

## Настройки

«Пуск» → **«WinShutDown — настройки»** → введите пароль родителя. Окно открывается из любой учётной записи,
в том числе из детской: нужен только пароль родителя, пароль администратора Windows не нужен. В окне можно:

- изменить расписание по дням недели и список предупреждений;
- включить или выключить голос и прослушать, как он звучит;
- временно отключить выключение по расписанию (галочка);
- **«Не выключать, пока за компьютером работает администратор Windows»** (включено по умолчанию, подробнее ниже);
- **«Разрешить посидеть подольше сегодня»** — продлить сегодняшний вечер на N минут
  (или отменить продление);
- сменить пароль;
- удалить программу.

### Управление из браузера — с другого компьютера или телефона

Менять настройки можно, не подходя к компьютеру ребёнка: с любого компьютера, телефона или планшета в той же
домашней сети (Wi-Fi). На свой компьютер ничего устанавливать не нужно.

1. Один раз на компьютере ребёнка: «Пуск» → «WinShutDown — настройки» → пароль → в разделе **«Управление по сети»**
   поставьте галочку **«Разрешить менять настройки из браузера…»** → «Сохранить».
2. На своём компьютере или телефоне откройте в браузере **`http://winshutdown.local:47800`** и введите **пароль родителя**.

Адрес `winshutdown.local` постоянный: компьютер ребёнка сам отвечает на это имя (по протоколу mDNS, как принтеры и
устройства Apple), поэтому адрес не зависит ни от IP, ни от типа сети в Windows. Он работает в Windows, macOS и на iPhone.
На Android такие адреса открываются не всегда, тогда используйте запасные адреса, которые показаны под галочкой:
`http://ИМЯ-ПК.local:47800` или адрес с цифрами `http://192.168.…:47800`.

В браузере можно посмотреть, когда будет следующее выключение, продлить время на сегодня, изменить расписание по дням,
предупреждения, голос и «не выключать при администраторе». Сменить пароль, удалить или обновить программу можно только
на самом компьютере ребёнка. Если компьютер ребёнка выключен, страница, конечно, не откроется.

Советы:
- Сохраните `http://winshutdown.local:47800` в закладках браузера.
- Если в доме несколько компьютеров с WinShutDown (например, у двоих детей), `winshutdown.local` откроет какой-то
  один из них. Для конкретного компьютера используйте его собственный адрес `http://ИМЯ-ПК.local:47800`.
- Если пользуетесь адресом с цифрами (например, на Android), учтите: он может смениться после перезагрузки роутера.
  Чтобы этого не было, закрепите адрес за компьютером ребёнка в настройках роутера («резервирование DHCP»).

Безопасность:
- **Пароль по сети не передаётся.** Страница получает от компьютера ребёнка одноразовое число и подписывает им каждый
  запрос, используя ключ, вычисленный из пароля (PBKDF2 + HMAC-SHA256). Перехваченный запрос нельзя ни повторить,
  ни изменить.
- После 5 неверных паролей вход блокируется на 5 минут, и на компьютере, и через браузер.
- Подключения принимаются только из домашней сети. Правило брандмауэра Windows, которое программа добавляет при
  установке, тоже пускает только локальную подсеть.
- По умолчанию управление через браузер **выключено**. Пока галочка не стоит, программа вообще не принимает подключений по сети.
- Если стоит сторонний антивирус со своим брандмауэром (Kaspersky, ESET и т. п.), ему может понадобиться разрешить
  входящие подключения к `WinShutDown.exe`: TCP 47800 (страница) и UDP 5353 (имя `winshutdown.local`).

### Если компьютер срочно нужен вам в запрещённое время

**Войдите под своей учётной записью администратора.** Пока вы работаете в ней, программа не предупреждает и не
выключает компьютер, а в окне настроек написано «Сейчас за компьютером администратор». Ребёнок в эту учётную запись
не войдёт, потому что не знает её пароля.

- Если включить компьютер в запрещённое время, на вход в Windows есть время последнего предупреждения (например,
  5 минут). Если не успели, компьютер выключится; включите его снова.
- Когда вы выйдете из своей учётной записи или переключитесь на учётную запись ребёнка, ограничения снова начнут
  действовать. Если сейчас запрещённое время, ребёнок получит обычное предупреждение («Осталось 5 минут…»).
- Если вы заблокируете свою учётную запись (Win+L) и отойдёте, компьютер не выключится: сеанс администратора
  остаётся активным. Например, можно оставить что-то скачиваться на ночь. Если ребёнок с экрана блокировки войдёт
  в свою учётную запись, ограничения сразу начнут действовать.
- Экран входа в Windows от ограничений не освобождает. Иначе можно было бы получать «ещё 5 минут», выходя на экран
  входа и возвращаясь.

Если нужно дать время ребёнку, используйте **«Разрешить посидеть подольше сегодня»**: это работает из любой учётной записи.

### Файл настроек

Настройки хранятся в файле `C:\ProgramData\WinShutDown\config.ini`. Его можно править вручную в Блокноте,
**запущенном от имени администратора** (у обычного пользователя доступа к файлу нет). Служба сама перечитает файл
примерно через секунду. Пример:

```ini
Enabled=1
Monday=07:00-22:00
Tuesday=07:00-22:00
Wednesday=07:00-22:00
Thursday=07:00-22:00
Friday=07:00-23:30
Saturday=09:00-00:30
Sunday=free
Warnings=30,10,5
Voice=1
AdminExempt=1
RemoteAdmin=0
```

`free` — день без ограничений. Строки с ошибками игнорируются (для такого дня остаётся время по умолчанию),
поэтому после правки загляните в окно настроек и проверьте строку «Следующее выключение». Строки `Password` и
`ExtensionUntilUtc` не трогайте.

## Как устроена защита

| Что может попробовать ребёнок | Что произойдёт |
|---|---|
| Завершить программу в диспетчере задач | Основная часть работает как служба Windows от имени SYSTEM. Обычный пользователь не может её остановить или завершить («Отказано в доступе»). Если служба всё же упадёт, Windows перезапустит её через 2 секунды |
| Закрыть надпись «Осталось X минут» | Alt+F4 на неё не действует, а «Снять задачу» выдаёт «Отказано в доступе». Если окно как-то закроется, служба покажет его снова через пару секунд. Выключение всё равно произойдёт: его выполняет служба |
| Отменить выключение командой `shutdown /a` | Не сработает: выключение запускается без задержки, отменять нечего |
| Перевести часы назад | Обычный пользователь не может менять системное время |
| Сменить часовой пояс | Не поможет: программа считает время в часовом поясе из своих настроек |
| Уйти в сон и проснуться ночью | После пробуждения в запретное время компьютер выключится через время последнего предупреждения (например, 5 минут) |
| Включить компьютер снова ночью или рано утром | Выключится через время последнего предупреждения. Но если разрешённое время начнётся в эти несколько минут (включил в 06:57, а можно с 07:00), выключения не будет |
| Играть в полноэкранную игру, чтобы не видеть надпись | Голосовые предупреждения всё равно слышно, а компьютер выключится по расписанию |
| Загрузиться в безопасном режиме | Служба запускается и в безопасном режиме |
| Подобрать пароль | После 5 неверных попыток вход блокируется на 5 минут. Пароль хранится только в виде хэша (PBKDF2-SHA256) |
| Выйти на экран входа и вернуться, чтобы получить ещё несколько минут | Не сработает: экран входа от ограничений не освобождает, отсчёт продолжается |
| Зайти в веб-админку со своего компьютера | Нужен пароль родителя; подбор блокируется так же, как на компьютере. Сменить пароль или удалить программу через браузер нельзя |
| Изменить файлы программы или настроек | Папки `C:\Program Files\WinShutDown` и `C:\ProgramData\WinShutDown` защищены: обычный пользователь не может их менять, а в папку настроек — даже заглянуть |
| Удалить программу | Нужны права администратора **и** пароль родителя |

**Чего программа не может** (и не может никакая программа без поддержки «железа»):
- если у ребёнка права администратора, защита обходится;
- загрузку с флешки или другой системы блокирует только пароль на BIOS/UEFI и запрет загрузки с USB. Поставьте их, если это актуально;
- если ребёнок выключит звук, голоса не будет слышно, но надпись всё равно будет видна (если игра не в эксклюзивном
  полноэкранном режиме), а компьютер всё равно выключится;
- **несохранённые данные при выключении теряются** — для этого и нужно предупреждение.

## Если забыли пароль

Войдите в учётную запись администратора и выполните в «Пуск → Выполнить» (Win+R):

```
"C:\Program Files\WinShutDown\WinShutDown.exe" --reset-password
```

Windows запросит права администратора, после этого можно задать новый пароль.

## Обновление до новой версии

Удалять старую версию не нужно. Расписание, пароль и все настройки сохранятся.

1. Скопируйте новый `WinShutDown.exe` на компьютер (например, в «Загрузки») и запустите его.
2. Программа увидит, что установлена другая версия, и предложит обновиться: нажмите **«Да»**.
   («Нет» — просто откроются настройки установленной версии.)
3. Windows запросит права администратора, затем программа спросит **пароль родителя**.
4. Служба остановится, файл программы заменится, служба снова запустится. Это займёт несколько секунд.
   В конце появится сообщение с номером установленной версии.

Номер установленной версии виден в заголовке окна настроек, например «WinShutDown 1.1.0 — настройки».
Если файл программы по какой-то причине заменить не удастся, служба всё равно запустится снова, в прежней версии:
защита не останется выключенной.

Если в Windows отключён контроль учётных записей (UAC), обновляйте из учётной записи администратора.

## Удаление

«Пуск» → «WinShutDown — настройки» → пароль → **«Удалить программу…»**. Нужны пароль родителя и права администратора.

## Журнал

Журнал работы службы хранится в файле `C:\ProgramData\WinShutDown\log.txt`. В нём видно, когда показывалось предупреждение,
когда компьютер выключался и когда вводился неверный пароль. Открыть файл можно только с правами администратора.

## Если что-то не работает

Программа ведёт журналы диагностики. Чтобы их открыть, нажмите Win+R и вставьте путь:

| Что не так | Журнал |
|---|---|
| Не открывается окно установки или настроек | `%TEMP%\WinShutDown.log` (в той учётной записи, где запускали программу) |
| Не появляется надпись или нет голоса | `%TEMP%\WinShutDown-agent.log` (в учётной записи ребёнка) |
| Компьютер не выключается вовремя | `C:\ProgramData\WinShutDown\log.txt` (нужны права администратора) |

Частые причины:
- **Запуск ничего не показывает, а в журнале есть строка «UAC отключён=True».** Контроль учётных записей отключён, и
  программу запустили из обычной учётной записи. Войдите под администратором и запустите программу ещё раз.
- **Сообщение про .NET Framework.** Это старая версия Windows 10 (до 1803). Обновите Windows или установите
  .NET Framework 4.8 с сайта Microsoft.

## Для разработчика

Сборка (нужен .NET SDK и пакет для .NET Framework 4.7.2 из Visual Studio):

```
dotnet build -c Release
```

Один exe работает в нескольких режимах:

| Аргументы | Режим |
|---|---|
| *(без аргументов)* | установка (если не установлено) или окно настроек |
| `--service` | служба Windows (запускается системой) |
| `--agent` | окно предупреждения (запускается службой в сеансе пользователя) |
| `--uninstall`, `--reset-password` | удаление / сброс пароля |
| `--update` | обновление установленной версии этим файлом (то же, что «Да» в вопросе об обновлении) |
| `--console … --allow-remote --port 47810` | тестовая служба с включённой веб-админкой; в тестовом режиме она слушает только `127.0.0.1`, а ответы на имя `winshutdown.local` — на `127.0.0.1:5354` (`--mdns-port`) |

Веб-админка — файл [`src/Web/admin.html`](src/Web/admin.html), вшитый в exe. Сервер — [`src/WebAdmin.cs`](src/WebAdmin.cs)
(минимальный HTTP поверх `TcpListener`, без http.sys).
| `--selftest --out файл.txt` | самопроверка логики расписания, текстов, пароля и протокола |
| `--console --password 1234 --shutdown 23:00 --allow 07:00 --warn 30,10,5` | тестовый запуск логики службы от текущего пользователя. **Компьютер не выключается**, только пишется запись в журнал (`%TEMP%\WinShutDown-test\log.txt`) |
| `--test --pipe WinShutDown.Test` | окно настроек, подключённое к тестовому `--console` |

Исходники лежат в папке `src/`. Основная логика — в `Engine.cs`, расчёт времени — в `Schedule.cs`,
окно предупреждения — в `Agent.cs`, установка — в `Installer.cs`.
